# SEO 基线审计

审计对象：本地生产构建，预期正式域名为 `https://lewiszhou.dev`。

## 已验证

- 中英文首页、文章列表、文章详情和关于页均有唯一 title、description 与 canonical。
- 每个 HTML 页面只有一个 H1。
- 每对翻译页面都输出自引用且双向对应的 `zh-CN` / `en` hreflang。
- 中文保留原 URL，英文使用 `/en/`，没有基于浏览器或 IP 的自动跳转。
- `robots.txt` 允许公开抓取，并声明完整 sitemap 地址。
- Astro 构建自动生成 `sitemap-index.xml` 与 `sitemap-0.xml`。
- 8 个 canonical 页面均被 sitemap 收录。
- 全站输出 `Person`、`WebSite` 和 `WebPage` JSON-LD。
- 文章输出 `BlogPosting` JSON-LD、文章 Open Graph 字段和可见作者链接。
- 中文首页、英文首页与文章页的生产构建 Lighthouse 四项均为 100。
- 本地 Lighthouse：LCP 0.9 秒、CLS 0、TBT 0 毫秒。
- npm 官方安全审计为 0 vulnerabilities。

## 尚未验证

- 域名尚未购买和解析，HTTPS、重定向与线上 canonical 尚未验证。
- 站点尚未公开，Google/Bing 收录状态和抓取错误尚无证据。
- Lighthouse 是本地实验室数据，不是 Search Console 的真实 Core Web Vitals。
- 尚无搜索查询、展示量、点击率、关键词排名或反向链接数据。
- 当前只有一篇文章，不足以判断主题权威度与内部链接效果。

## 上线后动作

1. 验证生产域名、HTTPS 和 HTTP 到 HTTPS 重定向。
2. 在 Google Search Console 验证域名并提交 `/sitemap-index.xml`。
3. 用 URL Inspection 检查首页、关于页和首篇文章的渲染与索引状态。
4. 用 Rich Results Test 验证线上 `BlogPosting`。
5. 积累 5–10 篇内容后，再按真实查询设计主题集群、栏目页与内部链接。
6. 每篇文章提供与正文内容对应的分享图后，再把该图片加入文章结构化数据。
