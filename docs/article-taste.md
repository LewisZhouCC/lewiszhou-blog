# 全站设计规则

参考：[Developing Taste](https://emilkowal.ski/ui/developing-taste)、[Agents with Taste](https://emilkowal.ski/ui/agents-with-taste)。

## 已确认的参考事实

2026-10-13 读取参考页 HTML：外层最大宽度为 692px，左右 padding 为 24px；标题使用无衬线和中等偏粗字重；段落底部间距为 26px。本文参数是本博客的设计选择，不能当作参考网站的原样复刻。

## 本地实现规则

| 项目 | 规则 | 原因 |
| --- | --- | --- |
| 阅读宽度 | 文章页最大 640px，移动端左右各 20px | 控制长文横向阅读距离；中英文共享同一阅读轴线 |
| 字体 | 复用 Avenir Next / PingFang SC 字体栈，标题用 650 字重 | 用字重与间距建立层级，避免新增字体请求 |
| 标题 | H1 约 26–36px，H2 20px | 长标题维持清晰层级，不压过正文 |
| 正文 | 桌面 17px，移动端 16px；中文行高 1.9，英文 1.75 | 分别适配两种文字的阅读密度 |
| 段落 | 段后 24px；章节前 44px | 区分连续论述和章节切换 |
| 颜色 | 中性浅底、深灰正文、灰色次要信息、少量蓝色反馈 | 保持阅读焦点，同时保留链接反馈 |
| 链接 | 正文链接常显细下划线，悬停加深，键盘焦点显示轮廓 | 点击与键盘操作都有明确提示 |
| 动效 | 仅链接颜色过渡 150ms；遵循 reduced-motion | 反馈及时，阅读位置稳定 |
| 表格与代码 | 保留原生表格，移动端和代码块局部滚动 | 长内容不撑破页面 |

## 验证与范围

文章页第一版已获用户认可。首页同步相同阅读宽度、背景、字体层级、链接反馈和页头页脚；文章列表取消装饰编号和悬停位移，主题入口使用轻边框。中英文文章列表与主题分类页也同步相同规则，列表保留摘要、分类和日期；关于页及导航入口已按用户要求移除；旧地址 301 跳转至对应语言首页，作者链接与 Person 数据指向首页。全站使用同一默认主题，移除旧纸面主题、衬线展示字体及逐页启用标记，新增页面直接继承公共样式。正文、双语路径、canonical、hreflang、结构化数据保持现有生成逻辑。

本地执行 `npm run build` 检查构建及 SEO。首页的桌面、移动端、中英文实际视觉效果仍需浏览器核对。当前环境没有可用的浏览器自动化连接，不能把源码核对称为视觉验收。

先确认真实文章页效果，再将稳定规则整理成个人 Skill；本轮不安装第三方 Skill，不添加动画库或设计系统。
